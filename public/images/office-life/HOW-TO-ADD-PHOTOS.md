# How to add photos here

1. Drag your photo files (.jpg, .png, or .webp) into this folder.
2. Name them however you like — e.g. "offsite-2026.jpg". No spaces needed, but avoid special characters like é, à, ç.
3. (Optional) To control the caption shown under a photo, create/edit a file
   called `captions.json` in this same folder, like this:

   {
     "offsite-2026.jpg": "Our 2026 team offsite in Grand Baie"
   }

   If you skip this, the filename itself becomes the caption
   (e.g. "offsite-2026.jpg" -> "Offsite 2026").
4. Commit and push to GitHub (or drag the files into GitHub's web upload
   page for this folder) — Vercel will redeploy automatically and the
   photos will appear on the site. No code changes needed.

Delete this file once you're comfortable — it's just instructions, not
used by the site.
